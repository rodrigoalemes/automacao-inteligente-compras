# Como funciona

1. **Entrada** — a solicitação de compra chega com seus documentos.
2. **Processamento** — os documentos são lidos e as informações relevantes extraídas automaticamente.
3. **Análise com IA** — a IA apoia a interpretação e a organização das informações.
4. **Consultas e relatórios** — os dados alimentam consultas e relatórios para a equipe.
5. **Validação** — a equipe de Compras valida o resultado, que retroalimenta os ajustes da solução.
